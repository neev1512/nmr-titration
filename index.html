How to use this tool

There's no code to run. Type your values and the results update right away.

Typical workflow

  1. Plan (tab 1). Enter your protein concentration and a few Kd values you think are plausible. Adjust your ligand concentrations until the circles are spread along the rising part of the curves, not bunched at the flat top.
  2. Get the pipetting recipe (tab 2). Paste the same ligand concentrations and your sample volume. The table shows how many µL to swap between tubes A and B at each step, and the chips show the order in which to measure the points.
  3. Run the first swap at the bench. Measure A0, B0, and A1.
  4. Estimate Kd early (tab 3). Enter those concentrations and their CSPs. The curve your black circles sit on gives an approximate Kd. If it's far from what you planned for, go back to tab 1 and re-plan the remaining points.

Entering values

  • Separate multiple values with commas, e.g. 0.5, 5, 50. Scientific notation like 1e7 works.
  • Concentrations are in µM, volumes in µL, and CSPs in ppm.
  • In tabs 2 and 3, put A0 (lowest ligand) first and B0 (highest) last.
  • If something is wrong, a red message says what to fix and the box is outlined. The results come back as soon as you correct it.
  • Reset to example values restores the notebook's example inputs.

Saving results

  • Export → PDF report puts all your inputs, both plots, the swapping table and the titration points into one document. In the print window, choose Save as PDF.
  • Export → All files (ZIP) downloads everything at once: both plots as PNG, the data behind every plot and table as CSV (opens in Excel), and a text file listing your inputs.
  • Each tab also has its own buttons: Save plot as PNG (high resolution, white background) and Download data (CSV).
  • Nothing is saved automatically. Your inputs reset when you close or reload the page.

Good to know

  • Online version: neev1512.github.io/nmr-titration. Open it in Chrome or Edge and click Install app (in Safari: File → Add to Dock) to get it as an app that also works offline.
  • The standalone HTML file works offline too and needs no installation. Share it by copying the file.
  • The model assumes 1:1 binding (P + L ⇌ PL) in fast exchange.
